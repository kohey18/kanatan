# Kanatan LP 画像生成プロンプト集（GPT Image 2.0用）

LP（`docs/index.html`）の placehold.jp 仮画像を差し替えるためのプロンプト。
**各コードブロックがそのまま1回分の入力**です。スタイル指定・サイズ指定込みで完結しているので、コピーしてそのまま貼り付けてください。

なお **ヘッダーロゴ（56×56）とヒーローのアプリアイコン（160×160）は生成不要**。既存のKanatanアイコン（`Resources/Assets.xcassets/AppIcon.appiconset/icon_512.png`）を流用します。

---

## 差し替え手順

1. 生成した画像を上記の保存名で `docs/assets/` に保存
2. `docs/index.html` の該当する `https://placehold.jp/...` を相対パス（`assets/xxx.png`）に置換
3. 表示サイズは `width`/`height` 属性で固定済みなので画像側の縮小は不要（気になる場合のみ `sips -Z 960 hero-demo.png` などで縮小）
